## Power BI Dashboard Guide

This guide summarizes the Power BI report built on top of the AI-powered BI pipeline outputs.

### Data sources

Load these CSVs via **Get data → Text/CSV**:

- `output/cleaned_data.csv` – fact table of orders.
- `output/kpi_metrics.csv` – optional precomputed KPIs.
- `output/customer_segments.csv` – per-customer features and segments.
- `output/ai_insights.csv` – AI-generated bullet-point insights.

In **Model view**:

- Create a relationship `cleaned_data[customer_id]` → `customer_segments[customer_id]` (Many-to-One, single direction from `cleaned_data` to `customer_segments`).
- Measures for interactive KPIs are defined on top of `cleaned_data` (not `kpi_metrics`).

### Measures (DAX)

Create these measures on the `cleaned_data` table:

```DAX
Total Revenue =
SUM ( cleaned_data[order_value] )

Total Orders =
COUNTROWS ( cleaned_data )

Average Order Value =
DIVIDE ( [Total Revenue], [Total Orders] )

Unique Customers =
DISTINCTCOUNT ( cleaned_data[customer_id] )
```

You can reuse these measures across all pages.

### Page 1 – Executive Dashboard

- **Cards**
  - 4 card visuals using the measures:
    - `Total Revenue`
    - `Total Orders`
    - `Average Order Value`
    - `Unique Customers`
- **Line chart – Monthly revenue**
  - Axis: `cleaned_data[order_date]` (month or continuous date).
  - Values: `Total Revenue`.
- **Bar chart – Revenue by category**
  - Axis: `cleaned_data[product_category]`.
  - Values: `Total Revenue`.
- **Slicers**
  - `order_date` (Between).
  - `product_category`.
  - `customer_region`.

All visuals on this page respond to the slicers because they are based on `cleaned_data`.

### Page 2 – Customer Analytics

- **Segment summary (matrix)**
  - Rows: `customer_segments[segment]`.
  - Values:
    - Average of `total_spending`.
    - Average of `order_count`.
    - Average of `avg_order_value`.
- **Bar chart – customers per segment**
  - Axis: `segment`.
  - Values: count of `customer_id`.
- **Optional slicers**
  - `segment` slicer from `customer_segments`.
  - Existing date / category / region slicers from `cleaned_data` if needed.

This page helps compare behavior across segments (size, spend, frequency).

### Page 3 – Product Performance

- **Bar chart – revenue by category**
  - Axis: `product_category`.
  - Values: `Total Revenue`.
- **Stacked bar – revenue by category and region**
  - Axis: `product_category`.
  - Values: `Total Revenue`.
  - Legend: `customer_region`.
- **Line chart – revenue over time**
  - Axis: `order_date`.
  - Values: `Total Revenue`.
- **Slicers**
  - Same as Page 1 (date, product category, region).

Use this page to analyze which products and regions drive revenue and how performance changes over time.

### Page 4 – AI Insight Panel

- **Insights table**
  - Table visual bound to `ai_insights`.
  - Columns:
    - `insight_id`
    - `insight_text`
- **Context KPIs**
  - Reuse cards for `Total Revenue`, `Total Orders`, etc. at the top of the page.

This page surfaces narrative insights generated by the Gemini model, alongside the key metrics, for quick executive consumption.
